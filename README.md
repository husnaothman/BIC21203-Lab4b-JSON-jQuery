## 1. Introduction

This repository contains the work for Lab 4b, which focuses on client-side scripting using JSON, JavaScript, and jQuery. The purpose of this lab is to learn how to create and manage JSON data, retrieve data using the JavaScript `fetch()` API, and manipulate HTML elements using jQuery.

### Question 1: Create and Structure JSON Data

This question creates a JSON file containing information about two books, including their titles, authors, publication years and genres.

### Question 2: Retrieve and Display JSON Data

This program uses the JavaScript fetch() API to retrieve data from the JSON file and display the tittle of the first book, author of the second book and genres of both book.

### Question 3: Compare Native JavaScript and jQuery

This program uses jQuery such as `.text()` to modify text, `.addClass()` add CSS classes and `.on("click", ...)` handle button click events.

## 4. How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `books.html` and select **Open with Live Server**.
5. To test jQuery, open `jquery-dom.html` using Live Server.
6. Click the button to display the alert message.

**Note:** Use Live Server to run the HTML files because the `fetch()` API requires a local development server to retrieve the JSON file.
